## 질문
클라이언트: "평가자가 AI 봇을 사이트에 직접 붙여서 이미지를 보고 점수·정성평가를 채울 수 있냐?"

## 결론
- 기술적으로는 가능 (복붙형 / 에이전트형 둘 다). 완벽 차단은 불가능 (화면 캡처 후 다른 기기에서
  AI에 넣으면 서버가 알 방법이 없음) → "차단"보다 "흔적 기록 + 탐지" 방향으로 간다.
- API 로그(`ApiLoggingAspect`)로 확인 가능한 건 **"브랜드/제품 1건을 평가하는 데 걸린 시간"
  (임시저장·제출 버튼 클릭 간격)** 수준까지다.
- **"문항별 소요 시간"은 지금 구조로는 확인 불가능.** 프론트 코드 확인 결과:
  - `POST /{dataId}` (문항 1개 저장 API, `useSaveSurveyResponse`)는 정의만 있고 실제 화면
    (`ProductSurvey.tsx`, `BrandSurvey.tsx`) 어디서도 호출 안 됨 — 죽은 코드
  - 실제로는 `handleTempSave`에서 보듯 사용자가 "임시저장" 버튼을 눌러야 `save-all`(해당 데이터셋
    문항 전체)을 한 번에 저장함. 문항별 자동저장 없음.
  - `elapsed` 로그 필드는 서버 처리 시간이지 사용자 작업 시간이 아님 — 간격 분석은 로그 타임스탬프
    간 차이로 해야 함 (타임스탬프 정밀도는 초 단위까지)

## 클라이언트에게 전달한 내용
> 문항별 소요 시간까지는 확인이 어렵고, "브랜드/제품 1건을 평가하는 데 걸린 시간"(임시저장·제출
> 버튼 클릭 간격) 수준에서 이상 패턴(비정상적으로 빠르거나 간격이 균일한 경우)을 탐지하는 건 가능함.

## 추가 작업 범위로 제안한 것 (미착수)
- 정성평가 입력란 붙여넣기(paste) 이벤트 감지/로깅 — 가성비 1순위로 제안함.
  체류시간 기반 이상치 탐지보다 신뢰도 높고 구현 비용 낮음 (오탐 적음)
- 문항별 체류시간을 진짜로 보려면 프론트에 문항 단위 autosave 또는 최소 포커스/블러 이벤트 로깅 추가 필요
- IP/User-Agent 기반 판별은 기대치 낮춰야 함 — 에이전트형이든 사람이든 평가자 본인 세션으로 동작해서
  구분 안 됨
